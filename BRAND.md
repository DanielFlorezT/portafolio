# Identidad visual de Daniel Florez Thomas

La identidad combina violeta mineral, amarillo ámbar y un fondo claro. Conserva la tipografía Manrope del logo DFT y el punto de color como rasgo distintivo.

| Uso | Color |
| --- | --- |
| Principal: logo, botones y enlaces destacados | Violeta mineral `#6743B3` |
| Acentos, punto del logo y detalles | Amarillo ámbar `#EAB66A` |
| Texto principal | Grafito ciruela `#302A38` |
| Fondo principal | Blanco lavanda `#F8F6FB` |

El fondo claro predomina. Los botones principales llevan violeta y texto blanco; el amarillo ámbar se reserva para detalles y no se usa como texto pequeño sobre fondo claro.
